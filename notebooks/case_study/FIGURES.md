(Leiden / flat), amber `#AD7A23` (raw FoodOn / delta), purple `#5E47A6`

## Reproduce all figures

```bash
conda activate foodscholar
cd notebooks/case_study

# 0. (only if rebuilding the corpus from raw NER/NEL) — idempotent, offline:
python build_corpus.py            # -> data/annotated_with_abstracts.parquet + BGE cache

# 1. run the notebooks in order (fresh kernel each; needs ~4 GB free RAM)
python _run_nb.py NB1_setup_backbone.ipynb   # backbone + M1 + scale_comparison
python _run_nb.py NB2_themes.ipynb           # anchor-scoped themes + A/B (~3 min)
python _run_nb.py NB3_retrieval.ipynb        # flat vs graph retrieval + deltas
export GROQ_API_KEY=…                          # NB4 needs a real key (mock aborts)
python _run_nb.py NB4_cards.ipynb            # 3 Layer C cards + provenance
```

Run in order — NB1 persists the Layer A graph, NB2 adds the anchor Leiden themes,
NB3/NB4 reload that snapshot. Deterministic under `SEED=42` on a fixed numpy/BLAS
stack (theme ids are content-hashed, so a partition that spares a community keeps
its id). The one irreducible nondeterminism is the NB4 LLM *summary text*. Styling
lives in `cs_common.py` (`init_mpl`, `slide`, `kpi`, `chip`, `labelled_bars`) — edit
there to restyle every figure at once.
